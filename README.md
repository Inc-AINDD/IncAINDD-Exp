# Introduction

This repository is for experiments about IncAINDD. You can find out more about IncAINDD [here](https://github.com/Inc-AINDD/Batch-Inc_AINDD)

Due to the size limitation, we only provide several example datasets testing IncAINDD and evaluating the performance of IncAINDD against the batch approach. Other datasets can be constructed in the same format and used as input.

# Datasets
The four compressed files provided in this repository are:

- `CENSUS` : contains insertion, deletion, and mixed update scenarios with a 30% update ratio.

- `WIKI_Ins` : contains insertion scenarios with a 30% update ratio.

- `WIKI_Del` : contains deletion scenarios with a 30% update ratio.

- `WIKI_Mix` : contains mixed update scenarios with a 30% update ratio.

All datasets used in our experiments are derived from [Sawfish](https://github.com/HPI-Information-Systems/Sawfish/tree/main/datasets) and preprocessed into the required format.
